# TwinSelf

> Your second brain, with hands.
> 你的第二大脑，还长着手。

TwinSelf 是一个人的知识与执行系统：把真实问题的解决过程沉淀成可复用的判断，再让 AI 助手和一组小硬件把这些判断变成行动。

## 为什么做

不是为了做一个聊天机器人，而是为了回答三个问题：

1. 我做过的事，能不能被复用？
2. 我踩过的坑，能不能不再踩？
3. 我的判断，能不能交给一个系统去执行？

## 三个部分

| 部分 | 作用 | 状态 |
|---|---|---|
| **TwinSelf Memory** | 知识库：事实、决策、原则、技能、失败模式 | 规划中 |
| **TwinSelf Agent** | 助手：调用工具、执行任务、交回结果 | 规划中 |
| **TwinBench** | 硬件：控制器 + 端头，给 AI 手脚 | 原型中 |

## 原则

- **真实问题优先**：先解决自己每天遇到的问题，再谈产品。
- **决策留痕**：记录为什么选 A 不选 B，而不只是记录结果。
- **小步验证**：先自用，再给 5 个外部用户用。
- **安全边界**：涉及市电、无人值守的操作，默认断开、可审计、可回滚。

## 当前目标

早期原型阶段。第一个目标是跑通：

```
AC 通断 → 电流记录 → 日志 → MCP 调用 → pytest 触发
```

## 路线

- [ ] AC 端头 + 控制器最小闭环
- [ ] 决策记录模板
- [ ] MCP 工具接口
- [ ] 第二个端头（USB / 按键 / 串口）
- [ ] 5 个外部用户验证

## 关于名字

TwinSelf = 孪生的自我。

不是替代你，而是把你的判断和执行复制一份，让你不在场时也能继续推进。
